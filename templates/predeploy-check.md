# 公開部署前檢查表

## 資料

- [ ] 所有資料都是合成資料或已正式核准公開的資料
- [ ] 沒有姓名、學號、Email、手機或 mapping table
- [ ] 沒有可回推真實身分的識別碼
- [ ] 沒有過小群體或容易推論個人的統計結果

## 程式碼與設定

- [ ] 沒有 API key、密碼或 token
- [ ] `.env` 沒有提交到 Git
- [ ] `.env.*` 沒有提交到 Git，且 `.env.example` 只有 placeholder
- [ ] 已檢查 `.gitignore` 規則，沒有把秘密誤當成可部署前端資產
- [ ] 前端 bundle 沒有敏感資料
- [ ] 沒有不必要的外部 API 呼叫
- [ ] 若有匯出功能，匯出內容只會匯出合成資料；沒有匯出功能則標記 N/A

## 功能

- [ ] 各項量化指標定義正確，分子、分母與期間清楚
- [ ] 篩選後各項量化指標、圖表與明細同步更新
- [ ] 比較基準至少兩個（前一年度、歷年平均、量化基準）
- [ ] 異常判斷方式寫得出來
- [ ] 空資料狀態可理解
- [ ] 錯誤狀態不暴露內部路徑或設定
- [ ] 手機版可以基本使用

## 指標口徑

- [ ] 沒有人數、比例、率、平均值混用排序
- [ ] 整體率由「總分子 ÷ 總分母」計算，不是各組率平均
- [ ] 量化指標名稱包含足夠的分母資訊（例如「錄取後註冊率」而非「註冊率」）
- [ ] 圖表標題說明指標、群體與期間
- [ ] 沒有把相關性寫成因果性

## 視覺誠實

- [ ] 沒有截斷座標軸放大差距
- [ ] 沒有雙軸、無法解釋的 3D 或難讀圖例
- [ ] 顏色只用於語意（不是裝飾）
- [ ] 每張圖都說得出要回答的問題與後續行動

## 部署

- [ ] 已確認公開網址內容適合被任何人查看
- [ ] 已用無痕視窗或手機測試
- [ ] 已記錄部署網址與目前版本
- [ ] 清楚標示這是合成資料 prototype
