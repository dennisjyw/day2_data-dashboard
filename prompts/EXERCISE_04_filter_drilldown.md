# 練習 4：加入篩選與下鑽

## 目的

讓儀表板從靜態報表變成可以探索資料的介面。本練習完成後，至少有一個學年度篩選與一個第二維度篩選；兩者可同時使用，且所有量化指標、圖表與明細都根據同一組篩選後資料同步更新。篩選器只負責資料探索，不是權限邊界。

## 操作步驟

1. 貼上「提示詞 1」，加入學年度與系所兩個篩選器。
2. 選擇一個學年度與系所，確認所有量化指標、圖表與明細同步更新。
3. 貼上「提示詞 2」，加入清除篩選按鈕。
4. 需要下鑽或遇到同步問題時，依情況貼上「提示詞 3」或「提示詞 4」。

## 提示詞 1：加入學年度與第二維度篩選

```text
請先閱讀 data/data_dictionary.md 與 dashboard-brief.md，檢查目前的 React 19 + Vite + TypeScript 儀表板，再沿用既有的 Tailwind CSS 4 與 shadcn/ui 元件結構完成篩選功能。

請加入兩個篩選器：
1. 學年度篩選器：從已解析資料的 `academic_year` 動態取得 unique 值並排序。不要硬編碼 2021、2022、2023 或其他固定年份；預設狀態為「全部」，若 Brief 明確要求預設值，也只能使用資料中實際存在的值。
2. 系所篩選器：從資料的 `department` 動態取得 unique 值；若現有 Brief 選擇招生管道，也可改用 `admission_channel`，但不可捏造新的維度。

兩個篩選必須以 AND 組合。請先建立共用的篩選後資料集，再讓所有量化指標、圖表與明細都從這個資料集重新計算或取值：
- 比例指標先對篩選後資料加總分子與分母，再計算總分子 ÷ 總分母。
- 沒有資料時顯示可理解的空資料狀態，不要顯示 NaN、undefined 或誤導性的 0。
- 不要把篩選器當成登入、權限或資料保護機制；本專案仍是純前端 prototype，不要新增後端或權限系統。

完成後請說明篩選後資料集在哪裡建立，以及如何驗證指標與圖表使用的是同一個子集。
```

## 提示詞 2：加入清除篩選按鈕

```text
請在目前儀表板加入「清除篩選」按鈕，並依 README.md 與 AGENTS.md 保留現有技術棧與資料邊界。

按下後必須：
- 將學年度與第二維度篩選恢復為「全部」。
- 讓所有量化指標、圖表與明細恢復到全體資料。
- 清除任何圖表下鑽或選取中的群組。
- 若目前沒有篩選或沒有下鑽選取，按鈕狀態仍要容易理解。

請不要用重新載入頁面或寫死一組數字來恢復狀態；完成後說明修改檔案並執行適用的驗證。
```

## 提示詞 3：檢查篩選後指標沒有同步

```text
我選擇了學年度與某個系所，但畫面上的整體註冊率仍然是全體資料的數字。

請依 data/data_dictionary.md 檢查篩選流程。指標的分子與分母必須先套用相同的篩選條件，再分別加總：

篩選後錄取後註冊率 = SUM(篩選後 registered) / SUM(篩選後 admitted)

請找出是哪一個指標、圖表或明細仍使用未篩選資料，修正共用資料流程，並說明如何用一個 CSV 子集驗證結果。不要把篩選器改成權限機制，也不要加入後端服務。
```

## 提示詞 4：加入圖表下鑽（選做）

```text
請在不改變技術棧的前提下，加入圖表下鑽功能：點擊比較圖表中的系所或招生管道後，讓下方明細表格顯示該群組的資料列。

需求：
- 不使用彈窗，直接更新頁面下方的明細區塊。
- 將選中的群組寫入明確的 state，觸發明細重新渲染。
- 明細仍要受學年度與其他全域篩選條件限制。
- 有清除選取的方式，並在沒有結果時顯示空資料狀態。
- 不要把這個互動描述成權限或因果分析。
```

### 補充提示詞：排除圖表點擊沒有反應

如果點擊圖表沒有反應，可補充：

```text
我點了 recharts 的圖表長條，但明細表格沒有反應。請確認目前使用的 Bar 或 Line 元件是否正確綁定 `onClick`，並確認 handler 有更新選取群組的 state，且明細表格確實讀取該 state 與共用篩選後資料集。完成後請說明修正位置。
```

## 驗收標準

- [ ] 學年度選項由資料動態產生，沒有寫死年份。
- [ ] 第二個篩選器由資料動態產生，使用資料字典允許的維度。
- [ ] 兩個篩選同時生效，且採 AND 組合。
- [ ] 所有量化指標、圖表與明細使用同一個篩選後資料集。
- [ ] 篩選後比例可用對應 CSV 子集的 SUM(分子) ÷ SUM(分母) 重算。
- [ ] 清除篩選後恢復全體資料與預設狀態。
- [ ] 空資料狀態可理解，不出現 NaN、undefined 或誤導性的數字。
- [ ] 沒有把篩選器當成權限邊界，也沒有新增登入、後端或權限系統。
