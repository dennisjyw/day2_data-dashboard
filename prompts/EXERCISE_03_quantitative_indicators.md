# 練習 3：建立核心量化指標與圖表

## 目的

從 Dashboard Brief 的決策問題選擇有用的量化指標與圖表，讓視覺化回答問題，而不是只增加裝飾。本練習完成後，畫面至少要有「結果」層的量化指標，以及「趨勢」層的年度趨勢圖；所有數值都能回溯到合成 CSV，且不把相關性寫成因果性。

## 操作步驟

1. 確認 `dashboard-brief.md` 已定義要回答的問題。
2. 貼上「提示詞 1」，請 AI 加入 3–5 個指標與兩種圖表。
3. 數值或圖表有問題時，依情況貼上「提示詞 2」或「提示詞 3」。

## 提示詞 1：建立指標與兩種圖表

```text
請先閱讀 data/data_dictionary.md 與 dashboard-brief.md，並依這些文件檢查目前專案的既有程式碼。請沿用目前的 React 19 + Vite + TypeScript、Tailwind CSS 4、shadcn/ui 與既有元件結構，不要改用其他框架或新增不必要的服務。

請根據 Dashboard Brief 的核心問題完成以下工作：
1. 加入 3–5 個量化指標。可從整體錄取後註冊率、分組註冊率、報到後註冊率、休學率、跨學年度變化或 Brief 指定的指標中選擇，但每個指標都必須能回答一個明確問題。
2. 每個指標都要寫清楚分子、分母、單位、計算期間與比較基準；介面或 tooltip 也要讓使用者查到這些資訊。
3. 依 data/data_dictionary.md 的定義計算：錄取後註冊率為 `registered / admitted`，報到後註冊率為 `registered / reported`，休學率為 `leave_count / registered`。若要計算整體或篩選後的比例，必須先加總分子與分母，再用總分子 ÷ 總分母，不可以平均各列或各組的比例。
4. `avg_score` 與 `avg_credits` 是分組平均值，不可直接加總；若跨列合併沒有適當權重，請維持分組值或清楚標示為簡單平均。
5. 使用 `recharts` 加入兩種圖表：一張以 `academic_year` 為 X 軸的年度趨勢折線圖，以及一張依系所或招生管道比較的柱狀圖。欄位請依資料字典的中英文對應處理，不要捏造資料欄位。
6. 每張圖表標題都要說明指標、群體與期間，並且能對應 Dashboard Brief 的問題；不要把同一張圖只換顏色當成兩種圖表。
7. 不要使用 Chart.js 或 Highcharts，也不要把相關性寫成因果性。所有結論只能描述資料觀察或待驗證假設。

完成後請說明修改的檔案、每個指標的算式與分子／分母，並執行適用的驗證指令。
```

## 提示詞 2：修正整體率計算

```text
請重新檢查目前的「整體註冊率」與所有篩選後註冊率計算。

依 data/data_dictionary.md，正確算法應為：
- 錄取後註冊率 = SUM(registered) / SUM(admitted)
- 報到後註冊率 = SUM(registered) / SUM(reported)

請確認不是先計算各系所、各招生管道或各資料列的比例再取平均。修正後請：
1. 告訴我分子與分母各是多少。
2. 在計算邏輯附近補上清楚的算式註解或方法說明。
3. 用目前 CSV 的對應資料重算一次並說明結果。
4. 不要修改 CSV 欄位名稱，不要加入任何真實資料或因果解釋。
```

## 提示詞 3：修正年度趨勢圖與 tooltip

```text
請依 data/data_dictionary.md 檢查年度趨勢圖。

請使用目前專案的 `recharts`：
- X 軸使用 `academic_year`，並依資料中的實際學年度排序。
- Y 軸顯示明確定義的整體註冊率或 Brief 指定指標。
- tooltip 顯示指標名稱、群體、期間，以及該點使用的分子與分母。
- 圖表標題不要暗示因果，例如只能描述某期間某群體的註冊率變化。

若目前資料或欄位對應不足以支援某個顯示，請先指出限制，不要自行捏造日期、cohort 或數值。
```

## 驗收標準

- [ ] 有 3–5 個與決策問題相關的量化指標。
- [ ] 每個指標都能回溯到 CSV，且分子、分母、期間與比較基準清楚。
- [ ] 整體與分組比例使用總分子 ÷ 總分母，不是各組率平均。
- [ ] 至少有年度趨勢折線圖與系所或招生管道比較柱狀圖。
- [ ] 圖表標題說明指標、群體與期間。
- [ ] 每張圖表都回答明確問題，而不是裝飾性視覺化。
- [ ] 使用 `recharts`，沒有使用 Chart.js 或 Highcharts。
- [ ] 沒有把相關性寫成因果性。
