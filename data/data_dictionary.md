# 合成校務資料字典

## 資料用途

本資料供公開展示型儀表板練習使用。所有內容均為合成資料，不對應任何真實學生、真實學校或正式校務資料。

## 資料粒度與彙總規則

- 每一列代表一個「學年度 × 系所 × 招生管道」的彙總，共 342 列（2021–2026 學年度 × 19 系所 × 3 招生管道）；不是一位學生的一筆資料。
- `applicants`、`admitted`、`reported`、`registered` 與 `leave_count` 是人數欄位，依篩選條件可加總。
- 計算整體比例時，先加總分子與分母再相除；不要直接平均各列比例。
- `avg_score` 與 `avg_credits` 已是合成的分組平均值，不可加總。跨多列合併時，若沒有個體層級權重，只能標示為簡單平均或只呈現分組值。
- 本資料沒有觀測日期、最後更新時間、cohort、區域或單位類型欄位；儀表板不得自行捏造這些欄位或日期。
- `department` 與 `college` 取自國立臺北科技大學官網「教學單位」頁面公告之大學部日間學士班系所與所屬學院（19 系、6 學院），僅系所與學院名稱為真實名稱。
- `admitted`（招生名額）在同一「系所 × 招生管道」組合下，2021–2026 六個學年度數值完全相同，代表名額固定、不逐年變動；其中機械工程系、電機工程系、資訊工程系、電子工程系、光電工程系、經營管理系之部分管道，數值參考 114 學年度（2025）技專校院招生策略委員會網站（techadmi.edu.tw）查得之公開名額，其餘系所／管道之名額為依相同量級估算之合成數值，並非逐年查證之官方數字。
- `applicants`、`reported`、`registered`、`leave_count`、`avg_score`、`avg_credits` 每年皆為模擬產生，`reported/admitted`、`registered/reported`、`leave_count/registered` 之比例區間參照台灣頂尖大學常見統計區間設定，不代表北科大真實逐年統計。

## 欄位說明

CSV 第一列（header）已改為中文欄位名稱；下表列出中文欄位名與對應的原始英文欄位代稱（用於程式/公式參照）。

| 中文欄位名 | 對應英文代稱 | 型別 | 說明 |
|---|---|---|---|
| `學年度` | `academic_year` | string | 學年度，例如 `2023`、`2024`、`2025` |
| `學院` | `college` | string | 系所所屬學院（真實學院名稱） |
| `系所` | `department` | string | 系所名稱（真實系所名稱） |
| `招生管道` | `admission_channel` | string | 合成招生管道 |
| `報名人數` | `applicants` | integer | 報名人數 |
| `錄取人數` | `admitted` | integer | 錄取人數（招生名額，同系所×管道六年固定） |
| `報到人數` | `reported` | integer | 報到人數 |
| `註冊人數` | `registered` | integer | 註冊人數 |
| `休學人數` | `leave_count` | integer | 合成休學人數 |
| `平均成績` | `avg_score` | number | 合成平均成績 |
| `平均修課學分` | `avg_credits` | number | 合成平均修課學分 |

## 儀表板建議指標

- 報名人數。
- 錄取人數。
- 報到人數。
- 註冊人數。
- 註冊率：`registered / admitted`。
- 報到後註冊率：`registered / reported`。
- 休學率：`leave_count / registered`。
- 平均成績與平均修課學分。

顯示率時，標題與方法說明應寫出分子、分母與期間，例如「錄取後註冊率（registered / admitted，2025 學年度）」。

## 公開展示限制

- 不得加入姓名、學號、Email、手機或 mapping table。
- 不要使用 `subject_token`，避免學員誤以為假名化資料就適合公開部署。
- 所有列資料都應被視為公開資料。
- 合成資料只能示範介面與分析流程，不支持真實政策結論。
